# Cuadro — comandos

Frontend-only (React + Vite, JS/JSX, sin backend). Gestor: Bun.

- `bun install` — instalar dependencias (lockfile `bun.lock`)
- `bun run dev` — servidor de desarrollo (0.0.0.0:5173)
- `bun test` — tests del modelo (`bun:test`)
- `bun run lint` — Biome check
- `bun run build` — build de producción

Diseño orientativo: no valida el cumplimiento del REBT ni sustituye el proyecto o la verificación de un profesional.
